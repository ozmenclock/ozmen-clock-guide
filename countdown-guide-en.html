Countdown Clock User Guide

WiFi configurable LED countdown clock - shows the remaining time to a target date and time, with color settings, per-digit colors, night light and WiFi time sync.

This guide summarizes first setup, daily use, main tabs and troubleshooting steps.

1. First Setup

  1. Connect the device to a 5V power supply.
  2. Connect your phone or computer to COUNTDOWN-XXXXXX.
  3. Default device WiFi password: 12345678.
  4. Open 192.168.4.1 in your browser.
  5. Select language, time zone and home WiFi, then save.

First setup screen

The first setup screen opens automatically if the device has not been configured before. Choose the display language first, then select your country or the nearest time zone region. The selected region is used to convert internet time to the correct local time.

The device WiFi password field is optional. Leave it empty if you do not want to change it; the device WiFi password remains 12345678. In the home WiFi section, select the modem network used for NTP time updates.

Your phone may show a no internet warning. This is normal; the device WiFi is only used for setup. A brief disconnection may happen while joining home WiFi.

3. Countdown Setting

The Countdown tab is used to set the target date and time. Year, month, day, hour, minute and second values create the final target. After pressing save, the device calculates the remaining time automatically.

  • Day or year display can be used for long countdowns.
  • When the target is reached, the display stays at 00:00:00.
  • If the target changes, press save again.

If a past target time is selected, the countdown is treated as completed. Saving a new future target returns the device to normal countdown mode.

4. Color Settings

The Color tab controls the main display color and brightness. You can choose a preset color or use the custom color selector for a specific color.

Color profiles add animated or smooth transition effects. Solid is fixed color; Rainbow, Aurora, Lava, Prism and Fade create color transitions. Lower effect speed looks calmer, while higher speed looks more active.

Per-digit colors allow each digit to use its own selected color. Dot color is adjusted separately.

High brightness is easier to see during the day, but uses more power. Lower brightness is usually more comfortable at night or indoors.

5. WiFi and Time

The WiFi tab connects the device to the home or workplace modem. When internet is available, the device can update time using NTP. The selected time zone region converts internet time to local time.

The WiFi status area can show the connected network name, local IP address, signal level and uptime. If the device is not connected, the saved network may still be shown, but IP and signal values can be empty.

After connecting, the page may stop responding briefly. Wait a few seconds and reopen 192.168.4.1 if needed. This happens while the device switches to the modem network.

6. Night Light

The Night Light tab lowers brightness automatically during the selected time range. For example, it can use lower brightness between 23:00 and 07:00.

This is useful in bedrooms, shops or dark rooms. When the night period ends, the display returns to normal brightness.

7. Tools

  • Open first setup again.
  • Reset to factory settings.
  • Update firmware and filesystem.
  • Use LED test to check the LEDs.

The Tools section is mainly for maintenance and service. Factory reset clears saved WiFi and settings. Do not disconnect power during updates.
