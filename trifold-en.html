Custom color

Selects the normal clock color from the color wheel. Press Save Color to keep it.

Color presets

Tapping one of the 12 preset colors previews it immediately. Custom wheel colors use the save button.

Brightness

Sets LED brightness from 5-255. Press Save Brightness to keep it after restart.

Digit and dot colors

When enabled, each digit uses its own color. Digits 1-6 and dot LEDs are selected and saved separately.

Color profile

Selects Solid, Rainbow, Aurora, Lava, Prism and other effects. Effect speed controls animation speed; preview link shows examples.

Extra Modes

Countdown, Scoreboard and Stopwatch temporarily replace the normal clock display. Use Show Clock inside the active tab to return to the regular time display.

Countdown

Enter hours, minutes and seconds, then choose what the clock should do.

Time fieldsEnter hours, minutes and seconds for the countdown.
LED colorChoose the countdown display color, then press Save Countdown.
Show EnteredShows the entered time on the clock without starting. Useful before a race or event.
Start / PauseStarts or pauses the countdown.
Resume / ResetContinues from pause or returns to the saved time.
Show ClockReturns the LED display to normal time mode.

Scoreboard

Use it for three players or teams. Left, middle and right scores each use two digits.

+ / -Changes each score immediately on the LED display. No save is needed for score changes.
ColorsSet left, middle and right player/team colors separately.
Save ColorsSaves only the score colors, not the current score value.
Reset ScoresReturns all scores to zero.
Show ClockLeaves scoreboard mode and returns to the normal clock.

Stopwatch

Normal stopwatch counts elapsed time. Lap stopwatch starts after a countdown and increases the lap number when the saved lap time is reached.

Normal / LapSelect normal stopwatch or lap stopwatch. Lap mode shows lap number on the left.
Lap timeSet lap minutes and seconds. The display warns when 5 seconds remain.
ColorChoose stopwatch LED color and press Save Stopwatch Color.
StartStarts the selected stopwatch mode. Lap mode begins after the start countdown.
Stop / ResumePauses and continues the timer.
ResetClears the timer and lap count.

Night Light

On/OffEnables or disables Night Light mode.
StartSets the hour and minute when dimming begins.
EndSets the hour and minute when normal brightness returns.
BrightnessSelects the lower brightness used during night hours.

WiFi tab

UTC and NTP
