Digital Clock User Guide

WiFi configurable LED clock - automatic time keeping, color profiles, temperature display, countdown, scoreboard and stopwatch modes.

This tri-fold guide summarizes first setup, daily use, advanced settings and troubleshooting.

Opening flap

1. First Setup

  1. Connect the clock to power and wait for the LED display to turn on.
  2. Open the WiFi list on your phone or computer.
  3. Connect to DIGITAL-CLOCK-XXXXXX.
  4. Enter the default password: 12345678.
  5. Open 192.168.4.1 in your browser.

First setup screen

If the clock has not been set up before, the first setup screen appears. Choose language, country/city time zone, optional device WiFi password and home WiFi network.

The connection may briefly drop while saving the home WiFi network. Wait a few seconds and reopen 192.168.4.1 if needed.

2. Quick Start

  1. Open the WiFi tab and select your home WiFi network.
  2. Enter the WiFi password and press Connect and Save.
  3. Select the correct time zone for your country.
  4. If WiFi is connected, use NTP to update the time.
  5. Open Appearance to adjust color and brightness.

4. Appearance Settings

Custom color

Selects the normal clock color from the color wheel and stores it with Save Color.

Color presets

Use one of the 12 preset colors for quick selection.

Brightness

Adjusts LED brightness. Higher brightness uses more power.

Digit and dot colors

Each digit and dot LED color can be selected separately.

Color profile

Selects effects such as Solid, Rainbow, Aurora, Lava, Prism and Fade. Effect speed is adjustable.

Inside left

5. Time and Dots

12/24 hour format

The clock can show time in 24-hour or 12-hour format.

Dot LED behavior

Dots can blink or stay always on.

NTP time update

When connected to home WiFi, internet time is received and stored in the clock.

Update Time

Sends phone or computer time to the clock.

If internet is not available, the clock continues using its stored RTC time.

6. Temperature Display

  • If a sensor is installed, room temperature can be displayed.
  • Show Temperature briefly shows the measured temperature on the LED display.
  • Celsius or Fahrenheit can be selected.
  • Auto display controls how often and how long temperature appears.
  • Offset corrects readings if they are slightly high or low.
Inside middle

7. Night Light

Automatically lowers display brightness during sleeping hours.

  • Start: Hour and minute when night mode begins.
  • End: Hour and minute when normal brightness returns.
  • Night brightness: Lower brightness used during this period.
Low brightness is recommended for bedrooms and dark rooms.

8. Countdown

  1. Enter hours, minutes and seconds.
  2. Use Show Entered Time to preview before starting.
  3. Press Start.
  4. Use Pause and Resume to control it.
  5. Use Reset to return to the saved time.

Countdown LED color can be selected separately.

9. Scoreboard and Stopwatch

Scoreboard is used for 3 players or teams. Left, middle and right scores can have different colors.

Stopwatch can run in normal or lap mode. In lap mode, the lap count increases when the selected lap time is reached.

Back panel

10. WiFi and NTP

  • The WiFi tab shows network, MAC address, IP, signal and quality.
  • Scan WiFi Networks lists nearby networks.
  • Connect and Save stores home WiFi details.
  • UTC is set according to the region selected during first setup.
  • NTP can update the clock from internet time.
A brief disconnection may happen while connecting to WiFi. This is normal.

11. Tools and Confirmations

  • Device WiFi password can be changed with current password confirmation.
  • The first setup screen can be opened again.
  • Firmware update page is opened from the Tools tab.
  • LED test checks all LEDs.
  • Red actions ask for a centered confirmation dialog.
