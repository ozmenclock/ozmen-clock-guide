Digital Clock User Guide

WiFi configurable LED clock - automatic time keeping, color profiles, temperature display, countdown, scoreboard and stopwatch modes.

This guide explains first setup, daily use, advanced settings and troubleshooting.

Video and guides ozmenclock.github.io/ozmen-clock-guide

1. First Setup

  1. Connect the clock to power and wait for the LED display to turn on.
  2. Open the WiFi list on your phone or computer.
  3. Connect to DIGITAL-CLOCK-XXXXXX.
  4. Enter the default password: 12345678
  5. Open 192.168.4.1 in your browser.
Your phone may show a no internet warning. This is normal; this WiFi network is used to open the clock setup panel. While connecting to WiFi, a brief disconnection may happen; wait a few seconds and reopen 192.168.4.1 if needed.

First setup screen

If the clock has not been set up before, the first setup screen appears after opening 192.168.4.1. On this screen, choose the language, select your country or nearest city for the time zone, optionally change the device WiFi password, and connect the clock to the home WiFi network.

The connection may briefly drop while connecting to the home WiFi network. This is normal; wait a few seconds and reopen 192.168.4.1 if needed.

2. Quick Start

  1. Open the WiFi tab and select your home WiFi network.
  2. Enter the WiFi password and press Connect and Save.
  3. Select the correct UTC offset for your country.
  4. Use NTP Sync to update the clock from internet time.
  5. Open Appearance to adjust color and brightness.

4. Appearance Settings

Custom color

Choose a color from the color wheel and press Save Color.

Color presets

Tap a preset color for quick color selection. Use the save button to keep it.

Brightness

Adjust display brightness. Higher brightness is easier to see but uses more power.

Digit and dot colors

Each digit and dot LEDs can have separate colors. Dot color is independent from digit colors.

Color profile

Select animated profiles such as Rainbow, Aurora, Lava, Prism and Fade. Effect speed is adjustable.

5. Time and Dots

12/24 hour format

The clock can show time in 24-hour or 12-hour format.

Dot LED behavior

Dots can stay on or blink. Blinking dots show the time flow on the display.

Internet time update

When connected to home WiFi, the clock can get internet time and update its stored time.

Update from system time

The phone or computer time is shown in the panel. Press Update Time to send this time to the clock.

If internet is not available, the clock continues using its stored time information.

6. Temperature Display

If the model supports temperature measurement, it can show the room temperature.

  • Show Temperature: Briefly shows the measured temperature on the LED display.
  • Unit C/F: Select Celsius or Fahrenheit.
  • Auto show: Shows temperature at intervals while in clock mode.
  • Times per minute: Controls how often temperature is shown.
  • Show for: Controls how long temperature stays on screen.
  • Offset: Corrects the value if the reading is slightly high or low.

7. Night Light

Automatically lowers display brightness during sleeping hours.

  • Start: Hour and minute when night mode begins.
  • End: Hour and minute when night mode ends.
  • Night brightness: Brightness level used during this period.
Low brightness is recommended for bedrooms and dark rooms.

8. Countdown

  1. Enter hours, minutes and seconds.
  2. Use Show Entered Time to preview the time before starting.
  3. Press Start to begin countdown.
  4. Use Pause to stop temporarily and Resume to continue.
  5. Use Reset to return to the entered time.

Countdown color can be selected separately.

9. Scoreboard

On the 6-digit model, left, middle and right sections can be used for 3 players or teams.

  • + / -: Instantly increases or decreases the score.
  • Color box: Selects each team color.
  • Save Colors: Saves colors only, not the current score.
  • Show Clock: Returns from scoreboard to normal clock mode.

10. Stopwatch

Normal stopwatch

Starts, pauses, resumes and resets elapsed time.

Lap stopwatch

Increases lap count according to the saved lap duration. A short countdown is shown before start.

  • During the last 5 seconds, the display flashes quickly as a warning.
  • The left side shows lap count; middle/right sections show elapsed time.
  • Stopwatch color can be saved.

11. WiFi and NTP

  • Scan WiFi Networks: Lists nearby networks.
  • Connect and Save: Saves home WiFi information.
  • Disconnect WiFi: Disconnects WiFi but keeps saved network.
  • Forget Saved WiFi: Deletes saved home WiFi name and password.
  • UTC: Shows the UTC value selected during first setup. It is changed from the region selection, not from normal WiFi use.
  • NTP Sync: Gets internet time and updates the clock time.
Note: The connection may briefly drop while saving the home WiFi network. This is normal; wait a few seconds and reopen the page.

12. Tools and Safe Confirmations

The Tools tab contains service actions that are not used every day. Red or restart actions open a centered confirmation window.

  • Device WiFi password: Enter the current password, then the new password. The typed password can be shown before saving.
  • Open First Setup Again: Opens the region, language and first connection setup screen again.
  • Forget Saved WiFi: Deletes the saved home WiFi name and password, but does not change the device WiFi password.
  • Restore factory settings: Deletes saved WiFi and clock settings, then restarts the clock.
  • Firmware Update: Opens the web firmware update page.
  • LED Test: Starts a quick LED test for checking the display.
  • Cancel: Closes the confirmation window without making changes.
The normal WiFi tab is for connection and time sync. Maintenance actions are now collected in the Tools tab.

13. Factory Reset

If the WiFi password is forgotten or settings are incorrect, restore factory settings from the Tools tab. After reset, the device WiFi password returns to the default password: 12345678.

  1. Connect your phone or computer to DIGITAL-CLOCK-XXXXXX.
  2. Open 192.168.4.1 in your browser.
  3. Open the Tools tab.
  4. Press the Restore factory settings button.
  5. Confirm the centered confirmation window.
  6. The clock resets and restarts.
  7. Connect again to DIGITAL-CLOCK-XXXXXX and enter the default password: 12345678.

16. Use and Safety

  • Use the clock in a dry indoor environment.
  • Make sure the power supply is suitable for the LED count.
  • Very high brightness uses more power.
  • Do not remove power during firmware update.
  • Before shipping, check clock model, digit count and LED test.
This guide is prepared for the WiFi configurable digital clock. Features may vary by software version and clock model.
