Countdown Clock User Guide

WiFi configurable LED countdown clock shows the remaining time to a target date and time.

First setup, target date, color profiles, per-digit colors, WiFi, night light and maintenance steps.

Quick Access

Default password: 12345678

Setup address: 192.168.4.1

Scan the QR code for video guide, detailed guides and PDF files.

A no internet warning may appear. This is normal; the device WiFi is only used to open the setup page.

Who Is It For?

Useful for events, openings, campaigns, weddings, sports halls, shop windows, New Year displays or any target date.

Settings are done from a phone or computer. No separate app is required for normal use.

Screen names in this guide may vary slightly depending on firmware version.

First Open

1. First Setup

  1. Connect the device to power.
  2. Connect to COUNTDOWN-XXXXXX WiFi.
  3. Enter password 12345678.
  4. Open 192.168.4.1 in your browser.
  5. Select language, time zone and home WiFi.
The device WiFi password is optional during first setup. Leave it empty to keep 12345678. Home WiFi is used for NTP time updates.

When setup is saved, the device stores the settings. If the page stops responding briefly, check that your phone is still connected to the device WiFi and reopen 192.168.4.1.

The device WiFi password is not the home router password. It is used only for joining the device network.

Setup Flow

1. Connect to device WiFi 2. Open 192.168.4.1 3. Select language and time zone 4. Select home WiFi and save

2. Countdown

Select target year, month, day, hour, minute and second. The remaining time is calculated after saving.

When finished, the display stays at 00:00:00. Save a new target to start countdown again.

For long countdowns, day or year display can be clearer. For short countdowns, hour, minute and second display is easier to read.

After changing the target date, press save so the new value is applied to the display.

4. Color

Single color, presets, effects and per-digit colors are available. When per-digit colors are enabled, each digit uses its own color. Dot color is adjusted separately.

Use higher brightness for daylight and lower brightness at night. Very high brightness uses more power.

5. Color Profiles

Color profiles add movement to the display. Solid is fixed color. Rainbow, Aurora, Lava, Prism and Fade create color transitions.

Lower effect speed gives calm transitions. Higher speed makes the colors more active.

For comfortable viewing, low speed and medium brightness usually look more balanced.

Inside Left

6. WiFi and NTP

  • Select home WiFi and enter the password.
  • NTP updates the clock time automatically.
  • A brief disconnection during connection is normal.
  • After connection, IP and signal information can be seen on the WiFi screen.

If WiFi is not connected, the device can still continue the countdown. The RTC module keeps time. When internet returns, NTP can update time again.

If the modem is far away or signal is weak, connection may take longer. Constant internet is not required for displaying time.

7. Time Zone

The region is selected during first setup. To change it later, open first setup again from Tools. Region selection keeps local time correct.

If the device is shipped to another country, the customer should choose the closest region for their location.

8. Device WiFi Password

This is not the home WiFi password. It is only used to connect to COUNTDOWN-XXXXXX. If changed, keep a note of the new password.

If the password is forgotten, factory reset may be needed.

Inside Center

9. Night Light

Reduces brightness during sleeping hours. Start, end and night brightness can be adjusted. The display returns to normal brightness after the night period.

For example, choose 23:00 start and 07:00 end to use lower brightness overnight.

10. Digit Colors

Each digit can use a different color. When enabled, every digit uses its selected color. This helps separate time sections on long countdowns.

Using different colors for days, hours, minutes and seconds makes the display easier to read from a distance.

11. Finish Effect

When the countdown reaches the target, the selected finish effect can be shown. During the effect, the display keeps 00:00:00.

Save a new target to use the countdown again.

Finish effect behavior may vary depending on settings and firmware version.

Back Cover

12. Tools

  • Open first setup again.
  • Reset factory settings.
  • Update firmware and filesystem.
  • Use LED test to check the LEDs.

Factory reset clears saved WiFi and settings. Use it only if setup is wrong or the device WiFi password is forgotten.

Before updating, make sure firmware and filesystem files belong to the correct project.

13. Safe Use

Do not disconnect power during updates. If the device WiFi password is forgotten, factory reset may be required. Factory reset clears saved WiFi and settings.

Use a 5V power adapter with enough current. More LEDs require more power.

An insufficient adapter can cause dim LEDs, restarts or unstable operation.

Keep the device away from water and moisture. Disconnect the adapter before wiring or servicing.

14. Troubleshooting

If the page does not open, make sure your phone is connected to the device WiFi. A brief disconnection while joining home WiFi is normal.

If color or target changes are not applied, press the save button again in the related tab.
